# 03 - Web estática e inscripción pública

## Objetivo
Entregar una experiencia accesible que no requiera servidor Next.js.

## Requisitos
- Usar `output: export`, metadatos, formulario semántico, estados de carga/error y límite de 10 MB.
- Solicitar consentimiento separado y explicar caducidad/borrado antes de enviar la selfie.
- No incluir claves AWS ni lógica privilegiada en el bundle.

## Aceptación
Build estático correcto y E2E que compruebe contenido, formulario y estado de configuración de API.
