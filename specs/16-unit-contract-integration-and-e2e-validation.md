# 16 - Validación integral

## Objetivo
Probar el flujo y las propiedades de seguridad, no solo módulos aislados.

## Requisitos
- Tests unitarios de contratos y estado, integración Lambda con clientes AWS simulados y E2E de formulario/galería.
- Plan Terraform validado, pruebas manuales de objetos privados, JWT y retención.
- Registrar fecha, entorno, datos autorizados, resultado y evidencia de cada demostración.
