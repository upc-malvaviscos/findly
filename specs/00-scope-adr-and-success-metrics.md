# 00 - Alcance, ADRs y métricas

## Objetivo
Congelar el MVP y definir evidencia de éxito antes de desplegar recursos.

## Requisitos
- Registrar ADR para serverless sin RDS, datos autorizados, una región y galería temporal.
- Medir inscripción completa, coincidencias, tiempo de procesamiento, coste previsto/real y borrado verificable.
- Excluir vigilancia, multi-región, HA, correo y datos no autorizados.

## Aceptación
El README, ADR y capítulo 02 coinciden; cada métrica tiene fuente, umbral y responsable.
