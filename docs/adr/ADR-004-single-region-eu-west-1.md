# ADR-004: Región única eu-west-1 para el MVP

## Estado

**ACEPTADO** (2026-09-03)

## Decisión

Los recursos del MVP se desplegarán exclusivamente en `eu-west-1`.

## Consecuencias

Se simplifican IAM, observabilidad, costes, evidencia académica y operaciones. No se ofrece recuperación ante desastre ni alta disponibilidad entre regiones durante el MVP.
